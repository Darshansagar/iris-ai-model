# Iris Flower Classifier

A simple machine learning model trained on the classic Iris dataset using
Logistic Regression, built in Google Colab.

## How it works
- Loads the Iris dataset (150 samples, 3 flower species)
- Splits into train/test sets
- Trains a Logistic Regression classifier
- Evaluates accuracy on the test set
- Saves the trained model

## Files
- `AI_Model_Practical.ipynb` — training notebook
- `iris_model.pkl` — saved trained model
